# 用法

三步走：写中文 → 点翻译 → 点出图。其余都是可选。

## 生成页

1. 左边「描述」写中文，一句话就够：`一个女生坐在咖啡馆窗边看书，午后自然光`
2. 点「翻译成提示词」，等 5~20 秒
3. 右边选尺寸（默认 512×768）、步数、CFG，点「开始生成」

右边参数说明：

| 参数 | 建议 |
|---|---|
| 尺寸 | 512×768（单人或双人）；要更清楚用 768×1024，8 GB 卡别再大 |
| 步数 | 32；25~40 都合理，低于 20 会糊 |
| CFG | 5.5；3~5 更写实，高于 9 容易糊 |
| 采样器 | dpmpp_2m_sde，调度器 karras |
| 种子 | 勾「随机」每次不同；取消后可填数字复现 |
| 张数 | 一次出几张 |

## 耦合页

把参考图里的主体特征套到生成的图上。

1. 「源目录」放参考图（每张图 = 一个母版）
2. 「输出目录」设好
3. 模式选 **单耦合**（只套 1 个主体，最快最稳）或 **多耦合**（按源图人数自动定）
4. 点「开始耦合」

参数：

| 参数 | 默认 | 含义 |
|---|---|---|
| 每张 | 1 | 每张源图生成几张 |
| 尺寸 × 倍率 | 512×768 × 1.5 | 成品 = 尺寸 × 倍率 = 768×1152 |
| LoRA | 0.6 | 脸部 LoRA 强度，越高越像但姿势僵 |
| FaceID | 0.8 | 参考图特征注入强度 |
| 修复强度 | 0.75 | 特征迁移后修复模型混合比例，高=磨皮 |

**倍率别低于 1.5**：1.0 等于放弃第二遍重绘，观感明显发软。

日志会顺手报相似度（0~1，越高越像），低于 0.6 会提示。

## 映射页

把母版人物的脸批量压到一个目录的图上。

1. 「母版」选一张参考脸
2. 「目标目录」放要处理的图，「输出目录」设好
3. 调「映射强度」（0.3~0.5 自然），点「开始映射」

**注意：这是全项目最弱的功能**，详见 README 的「短板」一节。侧脸、小脸、发型差异大都会失败。

## 英语学习

每次翻译同时产出英文句子和词表：

- 「隐藏词义」把中文换成圆点，自测用
- 「朗读」用系统 TTS 读句子
- 「导出」存成 Markdown 学习卡片

## 卸载模式（显存策略）

顶栏下拉三选一：

| 模式 | 行为 | 适用 |
|---|---|---|
| **按需**（默认） | 显存不够才让位 | 日常 |
| 出图优先 | 出图前总卸翻译模型 | 连续出图 |
| 翻译优先 | 翻译前总让 ComfyUI 让出 | 连续翻译 |

## 快捷键与细节

- 鼠标悬停在参数名上有说明（16 处）
- 预览面板：点「预览」覆盖日志，再点「收起」还原，双击图片用系统看图打开
- 左右分栏可拖，双击分隔条前后拖都跟手（已防抖）
- 「关闭服务」会同时结束 ComfyUI 和 Ollama，恢复需要重开软件

## 相似度怎么读

出图后日志会打印相似度（ArcFace 余弦，0~1）：

```
耦合   相似度 0↔0 0.89 ｜ 平均 0.89
映射   相似度 0.78
```

| 区间 | 含义 |
|---|---|
| 0.85 以上 | 很像，同一人 |
| 0.70~0.85 | 能认出是同一个人，细节有差 |
| 0.55~0.70 | 像但不像本人 |
| 0.55 以下 | 基本不是同一人（脸小、侧脸、被遮挡） |

实测参考值：

```
生成 → 耦合（单耦合，512×768 ×1.5）        0.86~0.90
映射：不同人物目标（强度 0.5）              0.11 → 0.78 / 0.16 → 0.80
映射：母版自身（上限校验）                  1.00 → 0.91
```

低于 0.55 时日志会给出提示，先考虑**脸在画面里是不是太小**或**构图是否侧脸**，而不是去调参数。

## 自定义翻译规则

`提示词规则.txt` 是发给翻译模型的系统提示词，定义了输出 JSON 的结构与风格。仓库里带的是通用版本，可以直接改：

- 想换提示词风格 → 改规则 3、6、10
- 想调整词表条数 → 改规则 11
- 想加固定后缀（比如统一加 `film grain`）→ 改规则 7 或示例

改完立即生效，不用重启软件。规则越长翻译越慢（见 [LESSONS.md](LESSONS.md) 的 A3 条），建议控制在 2000 字以内。
